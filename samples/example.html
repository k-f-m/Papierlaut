Reading HTML aloud

This file exists to exercise the HTML path. The parser keeps the readable body, drops navigation, headers and footers, and then hands the markup to the sanitiser before anything reaches the page.

Inline elements

A sentence can contain bold and italic runs, and even a word broken across tags such as Vorleser. The highlight follows the word regardless, because a word is allowed to be rendered as more than one span.

Lists and tables

  • Each list item is read as its own paragraph.
  • So is each table cell.
