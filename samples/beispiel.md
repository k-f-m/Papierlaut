# Papierlaut – ein deutsches Beispiel

Dieses Dokument dient zum Ausprobieren. Ziehen Sie es in das Fenster, und die
Anwendung liest es vor – Wort für Wort hervorgehoben.

## Warum lokal?

Sprachsynthese in der Cloud klingt gut, hat aber einen Preis: Der Text muss den
Rechner verlassen. Bei einem Vertragsentwurf, einem Arztbrief oder einem noch
unveröffentlichten Manuskript ist das keine Option.

Diese Anwendung geht deshalb einen anderen Weg. Das neuronale Modell läuft in
diesem Tab, als WebAssembly. Es gibt keine Anfrage an einen Server – der Browser
darf gar keine stellen.

## Was Sie ausprobieren sollten

1. Klicken Sie mitten im Text auf ein Wort. Die Wiedergabe beginnt dort.
2. Ändern Sie das Tempo, während vorgelesen wird.
3. Schalten Sie „Mitlaufen“ aus, und scrollen Sie selbst.

> Ein Zitat wird wie jeder andere Absatz gelesen; die Betonung ergibt sich aus
> der Zeichensetzung, nicht aus der Formatierung.
